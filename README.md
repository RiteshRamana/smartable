The main objective of the project is to meet the need of restaurants or other similar businesses in automating their tasks.
The Project consists of 2 main parts:
    i) The Customer End
    ii) The Restaurant End
The Customer End Program is to display the menu to the customer, get inputs on what he/she wishes to order, and display the bill in the end.
The Customer can also give feedback which will be stored in a file which can be viewed by the restaurant.
The Restaurant End enables the restaurant to add, modify or remove items from the menu, look at feedback from customers, and check data on most popular item, least favourite item and revenue in the month.
This project requires integration of csv module in Python
